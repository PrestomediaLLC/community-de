# Community-Support-Hub

Willkommen im öffentlichen Community-Support-Forum für Anwendungen von [Prestomedia](https://prestomedia.com/de)! 

Dieser Bereich ist für den Austausch von Nutzer zu Nutzer, Funktionswünsche und allgemeine Fragen und Antworten gedacht. Bitte beachten Sie, dass *dies ein öffentliches Community-Forum ist*.



## 📱 Wählen Sie Ihre Anwendung aus

Um eine Frage zu stellen, ein Problem zu melden oder eine Idee vorzuschlagen, klicken Sie unten auf die Diskussionskategorie Ihrer App:

* 📝 [**Free Text Editor**](https://github.com/PrestomediaLLC/community-de/discussions/categories/free-text-editor-com)
* 📊 [**Pro Diagrams**](https://github.com/PrestomediaLLC/community-de/discussions/categories/prodiagrams-com) (demnächst verfügbar)
* 📊 [**Free Diagrams**](https://github.com/PrestomediaLLC/community-de/discussions/categories/freediagrams-com) (demnächst verfügbar)
* 📊 [**Team Matcher**](https://github.com/PrestomediaLLC/community-de/discussions/categories/team-matcher-com) (demnächst verfügbar)

*(Wenn Sie innerhalb einer Kategorie auf **„New discussion“** klicken, führt Sie ein vorgefertigtes Formular durch das Erstellen Ihrer Nachricht.)*



## 📋 Community-Richtlinien

Bitte beachten Sie vor dem Verfassen eines Beitrags Folgendes:

1. **Zuerst suchen:** Überprüfen Sie bestehende Diskussionen in der Kategorie Ihrer App – möglicherweise wurde Ihre Frage oder Ihr Funktionswunsch bereits beantwortet.
2. **Schützen Sie Ihre Privatsphäre:** **Veröffentlichen Sie niemals private persönliche Daten**, E-Mail-Adressen, Passwörter, Lizenzschlüssel oder sensible Finanzdaten. Alle Beiträge sind vollständig öffentlich.
3. **Seien Sie respektvoll:** Behandeln Sie andere Community-Mitglieder mit Freundlichkeit. Freundliche, konstruktive Diskussionen helfen uns, bessere Apps für alle zu entwickeln!
